# create-xxx

基于 create-vue 官方脚手架,集成 Element Plus、Pinia、Vue Router、Axios 的 Vue 3 项目模板。

## 发布

```bash
pnpm pack
pnpm pack --dry-run
pnpm publish
```

## 使用

```bash
pnpm create @dengzhibo/vue3-template my-app
# 或
npx @dengzhibo/create-vue3-template my-app
```

创建后:

```bash
cd my-app
pnpm install
pnpm dev
```
