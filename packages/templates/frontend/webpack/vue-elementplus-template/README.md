# repository

Phase 0 monorepo foundation: pnpm workspaces, Turborepo, TypeScript, ESLint, Prettier, Vitest.

## Requirements

- Node.js >= 22 (development and CI use the version in `.node-version`)
- pnpm, via Corepack: `corepack enable`

## Getting started

```bash
corepack enable
pnpm install
pnpm verify        # lint, typecheck, test, build (cached by Turborepo)
```

## Commands

| Command                | What it does                                   |
| ---------------------- | ---------------------------------------------- |
| `pnpm verify`          | lint + typecheck + test + build for everything |
| `pnpm verify:affected` | the same, only for projects changed vs. `main` |
| `pnpm dev`             | run every project's `dev` script               |
| `pnpm format`          | format all files with Prettier                 |
| `pnpm check:boundaries`| enforce the dependency rules                   |

Single project: `pnpm --filter @acme/example-app <script>` or run the script inside its directory.

## Layout

```text
apps/       deployable units (never depended upon)
packages/   runtime libraries (named after a capability)
docs/       ADRs and guides
scripts/    repository tooling (check-boundaries)
```

`apps/example-app` and `packages/example-lib` are temporary samples that exercise the dependency graph,
caching and affected-only runs. Delete them when real projects exist.

## Rules in one minute

1. `apps -> packages`, never the reverse, never in a cycle.
2. A package needs two real consumers and a capability name. No `shared` or `utils`.
3. New environment variables go in `.env.example` and `turbo.json`.
4. Commits follow Conventional Commits (`feat: ...`, `fix: ...`).

Details: [docs/](docs/README.md).

## Renaming the package scope

The scope `@acme` is a placeholder. From the repository root:

```bash
# Linux
grep -rl "@acme" . --exclude-dir=node_modules --exclude-dir=.git | xargs sed -i 's/@acme/@your-org/g'
# macOS: use  sed -i ''  instead of  sed -i
```

## Troubleshooting

- pnpm reports "Ignored build scripts": run `pnpm approve-builds` and allow `esbuild`.
- CI fails on `--frozen-lockfile`: commit `pnpm-lock.yaml` (generated by the first `pnpm install`).
