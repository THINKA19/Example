# 国际化 (i18n) 配置说明

本项目已内置多语言支持，开箱即用。

## 支持的语言

- **中文（简体）** - `zh` - 默认语言
- **English** - `en`
- **Tiếng Việt** - `vi`

## 目录结构

```
src/
├── index.md          # 根路径首页（重定向到默认语言）
├── zh/               # 中文内容
│   ├── index.md      # 中文首页
│   ├── guide/        # 中文指南
│   └── api/          # 中文 API 文档
├── en/               # English content
│   ├── index.md      # English homepage
│   ├── guide/        # English guide
│   └── api/          # English API docs
└── vi/               # Nội dung tiếng Việt
    ├── index.md      # Trang chủ tiếng Việt
    ├── guide/        # Hướng dẫn tiếng Việt
    └── api/          # Tài liệu API tiếng Việt
```

## 配置文件

### 主配置 `.vitepress/config.ts`

主配置文件已集成 i18n 配置：

```ts
import { localesConfig } from './config/i18n'

export default defineConfig({
  // ... 其他配置
  locales: localesConfig,
})
```

### i18n 配置 `.vitepress/config/i18n.ts`

包含所有语言的详细配置，每个语言包括：

- `label`: 语言选择器显示的名称
- `lang`: HTML lang 属性
- `title`: 站点标题
- `description`: 站点描述
- `themeConfig`: 导航、侧边栏、UI 文案等

## 添加新语言

### 1. 创建语言目录

```bash
mkdir -p src/ja/guide src/ja/api
```

### 2. 创建内容文件

```bash
# 首页
echo "# 日本語ホーム" > src/ja/index.md

# 指南
echo "# はじめに" > src/ja/guide/index.md
```

### 3. 在 i18n.ts 中添加配置

```ts
// .vitepress/config/i18n.ts

export const jaConfig: LocaleSpecificConfig<DefaultTheme.Config> = {
  label: '日本語',
  lang: 'ja-JP',
  title: 'マイドキュメント',
  description: 'VitePressベースのドキュメント',
  
  themeConfig: {
    nav: [
      { text: 'ホーム', link: '/ja/' },
      { text: 'ガイド', link: '/ja/guide/' },
      { text: 'API', link: '/ja/api/' },
    ],
    sidebar: {
      '/ja/guide/': [
        {
          text: 'ガイド',
          items: [
            { text: 'はじめに', link: '/ja/guide/' },
          ],
        },
      ],
    },
    outline: {
      label: 'このページ',
    },
    docFooter: {
      prev: '前へ',
      next: '次へ',
    },
    // ... 更多本地化文案
  },
}

// 导出配置
export const localesConfig = {
  root: {
    label: '简体中文',
    lang: 'zh-CN',
  },
  zh: zhConfig,
  en: enConfig,
  vi: viConfig,
  ja: jaConfig,  // 添加新语言
}
```

### 4. 重启开发服务器

```bash
pnpm dev
```

## 语言切换器

VitePress 会自动在导航栏显示语言切换器，用户可以：

- 点击语言选择器切换语言
- 通过 URL 路径访问不同语言版本
  - 中文：`/zh/`
  - English: `/en/`
  - Tiếng Việt: `/vi/`

## 最佳实践

### 1. 保持内容同步

确保所有语言的内容结构一致，避免出现某个语言缺少页面的情况。

### 2. 使用一致的 URL 结构

所有语言的 URL 结构应该保持一致：

```
/zh/guide/getting-started
/en/guide/getting-started
/vi/guide/getting-started
```

### 3. 本地化所有 UI 文案

确保所有用户界面文案都进行了本地化，包括：

- 导航菜单
- 侧边栏标题
- 按钮文字
- 搜索提示
- 404 页面
- Footer

### 4. SEO 优化

每个语言版本应该有独立的 SEO 配置：

```ts
{
  lang: 'zh-CN',
  title: '中文标题',
  description: '中文描述',
}
```

## 故障排查

### 语言切换器不显示

确保在 `locales` 配置中至少有两个语言。

### 页面 404

检查：
1. 文件路径是否正确
2. 文件扩展名是否为 `.md`
3. frontmatter 是否有语法错误

### 搜索结果不正确

确保在 `search.ts` 中配置了对应语言的搜索翻译。
