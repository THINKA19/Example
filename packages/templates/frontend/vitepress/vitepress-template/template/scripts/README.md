# Scripts 自动化脚本说明

本目录包含 VitePress 项目的自动化辅助脚本。

## 📁 脚本列表

### generate-sidebar.ts

**功能**：自动扫描 `src/` 目录下的 Markdown 文件，根据目录结构生成侧边栏配置。

**使用方式**：
```bash
pnpm sidebar:generate
```

**工作原理**：
1. 递归扫描 `src/` 目录下的所有 `.md` 文件
2. 提取文件的 frontmatter 中的 `title` 字段作为导航标题
3. 根据目录结构生成多级嵌套的侧边栏配置
4. 输出到 `.vitepress/config/sidebar/auto-generated.ts`

**配置使用**：

在 `.vitepress/config/sidebar/index.ts` 中导入并使用：

```typescript
import { autoGeneratedSidebar } from './auto-generated'

export const sidebarConfig = {
  ...autoGeneratedSidebar,
  // 可以手动添加其他自定义配置
}
```

**注意事项**：
- 生成的配置文件会被完全覆盖，请勿手动修改
- 建议在 Git 中忽略自动生成的文件，或在 CI/CD 中自动执行
- Markdown 文件需包含 frontmatter 的 `title` 字段以获得更友好的标题

## 🔧 扩展开发

如需添加新的自动化脚本：

1. 在本目录创建新的 `.ts` 文件
2. 在 `package.json` 的 `scripts` 中添加对应命令
3. 更新本 README 文档
