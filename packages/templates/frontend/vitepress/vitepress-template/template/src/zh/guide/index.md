# 介绍

欢迎使用我们的文档站点！

## 这是什么？

这是一个基于 VitePress 构建的文档站点模板。它提供了：

- ✅ 完整的 TypeScript 支持
- ✅ 多语言国际化配置
- ✅ SEO 优化
- ✅ 暗黑模式支持
- ✅ 本地搜索功能

## 为什么选择 VitePress？

VitePress 是一个由 Vite 和 Vue 驱动的静态站点生成器，专为编写技术文档而设计。

### 核心特性

1. **简洁高效** - Markdown 为中心的内容创作
2. **快速开发** - Vite 提供即时热更新
3. **灵活定制** - Vue 组件自定义主题
4. **SEO 友好** - 自动生成 sitemap 和 meta 标签
