# Introduction

Welcome to our documentation site!

## What is this?

This is a documentation site template built with VitePress. It provides:

- ✅ Full TypeScript support
- ✅ Multi-language internationalization
- ✅ SEO optimization
- ✅ Dark mode support
- ✅ Local search functionality

## Why VitePress?

VitePress is a static site generator powered by Vite and Vue, designed for writing technical documentation.

### Key Features

1. **Simple & Efficient** - Markdown-centered content creation
2. **Fast Development** - Instant hot reload with Vite
3. **Flexible Customization** - Custom themes with Vue components
4. **SEO Friendly** - Auto-generated sitemap and meta tags
